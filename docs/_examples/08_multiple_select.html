Example 8 - multiple select

With the option multiSelect the user can select multiple nodes:

  • A click adds a node to the selection, or removes it when it is selected.
  • The arrow keys move the focus, and Space adds the focused node to the selection or removes it.

The function getSelectedNodes returns the selected nodes. The nodes must have an id.

{% highlight js %} var $tree = $('#tree1'); $tree.tree({ data: ExampleData.exampleData, autoOpen: true, multiSelect: true }); // Show the selected nodes. tree.select is triggered when a node is added to // the selection or removed from it. $tree.on('tree.select', function() { var names = $tree.tree('getSelectedNodes').map(function(node) { return node.name; }); $('#selected-nodes').text(names.length ? names.join(', ') : 'none'); }); {% endhighlight %}
