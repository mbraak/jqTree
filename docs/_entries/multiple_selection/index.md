Turn on the option [multiSelect](#options-multiselect) to let the user select multiple nodes with the mouse and the keyboard. See [Example 8 - multiple select](examples/08_multiple_select).

Jqtree also has some functions that can help you to implement multiple selection yourself.

In order for multiple selection to work, you must give the nodes an id.
